# 各章・付録の文字数集計方法

最新の集計結果は[各章の文字数・読了時間](./chapter_stats.md)を正本とする。

## 使い方

プロジェクトルートから次を実行する。

```bash
python3 scripts/count_chars.py
```

スクリプトは、PDF・EPUB・Vivliostyleと同じ順序で `chapters/` 内の全31ファイルを走査し、文字数と推定読了時間をMarkdownテーブルとして標準出力する。入力ファイルの網羅性と順序は `tests/review/test_book_input_order.py` で検証する。

## カウント方式

1ファイルにつき次の値を算出する。

- **文字数**: UTF-8で読み込んだMarkdown原稿に対する `len(text)`
- **本文文字数**: Markdown記法、コードブロック、参考文献、「さらに学びたい読者へ」を除いた本文
- **コード文字数**: コードブロック内の文字数
- **本文全角換算**: 本文文字列を全角1、半角0.5として換算
- **コード全角換算**: コード文字列を同じ方法で換算

本文とコードの抽出には [mistune](https://pypi.org/project/mistune/) を使用する。リンクは表示テキストだけを数え、画像とHTMLブロックは除外する。テーブルはセルの表示テキストを数える。

全角換算には `unicodedata.east_asian_width()` を用いる。`W` と `F` を全角、それ以外を半角として数え、半角幅の合計を2で割って端数を切り上げる。Ambiguousカテゴリも保守的に半角として扱う。

## 読了時間

本文とコードでは読む速度が異なるため、それぞれを別に計算して合算する。

| レベル | 本文 | コード | 想定読者 |
|-------|------|--------|---------|
| 初心者 | 200文字/分 | 80文字/分 | プログラミング未経験の実験系研究者 |
| 中級者 | 350文字/分 | 150文字/分 | ある程度のプログラミング経験がある研究者 |
| 上級者 | 500文字/分 | 250文字/分 | ソフトウェアエンジニア |
