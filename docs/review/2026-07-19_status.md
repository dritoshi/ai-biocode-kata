## 検証コマンド（orphan 再点検用）

参考文献リストの番号と本文の引用を突き合わせる。コードブロックと「さらに学びたい読者へ」節を除外し、`[N](url)` / `[[N]](url)` / 素の `[N]` を区別する。

```python
import re, glob, os
def strip_code(lines):
    out, inb = [], False
    for l in lines:
        if re.match(r'^\s*(>\s*)?```', l): inb = not inb; out.append(''); continue
        out.append('' if inb else re.sub(r'`[^`]*`', '', l))
    return out
for p in sorted(glob.glob('chapters/*.md')):
    lines = open(p).read().split('\n')
    ref_i = next((i for i,l in enumerate(lines) if re.match(r'^##+ *参考文献', l)), None)
    if ref_i is None: continue
    more_i = next((i for i,l in enumerate(lines) if re.match(r'^##+ *さらに学びたい', l)), ref_i)
    body = '\n'.join(strip_code(lines[:min(ref_i, more_i)]))
    listed = set(int(x) for x in re.findall(r'^-? *\[(\d+)\]', '\n'.join(lines[ref_i:]), re.M))
    linked = set(int(x) for x in re.findall(r'\[\[?(\d+)\]\]?\(', body))
    plain  = set(int(x) for x in re.findall(r'(?<!\[)\[(\d+)\](?!\()', body))
    if listed and (listed - linked - plain or (plain - linked) & listed):
        print(os.path.basename(p), '真orphan:', sorted(listed-linked-plain), 'リンク未付与:', sorted((plain-linked)&listed))
```
