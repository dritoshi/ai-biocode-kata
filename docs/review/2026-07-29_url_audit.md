# 原稿URL到達性・参照先監査

## 目的

`chapters/*.md` と、原稿から使用されている `references/*.bib` 項目に含まれる外部URLを再検査し、リンク切れ、転送先の不一致、検査器の誤判定を切り分ける。

## 実施条件

- 実施日: 2026-07-29
- 基準ブランチ: `revise/url-audit`
- 検査対象: 440 unique URLs、1,324 occurrences
- 検査コマンド: `python3 scripts/review/check_urls_all.py`
- 生データ: [`url_check.json`](./url_check.json)

## 機械検査結果

| カテゴリ | 件数 | 判定 |
|---|---:|---|
| `ok` | 422 | 到達確認済み |
| `redirect` | 1 | Google公式ページを別経路で到達確認済み |
| `anti-bot` | 13 | 12件は一次情報または過去の手動確認で有効性を確認済み。1件を任意ブラウザ確認へ引き継ぐ |
| `connection_error` | 4 | 検索サービスでは公式ページを取得でき、実URLの欠陥ではなく実行経路固有のタイムアウトと判定 |
| `error` | 0 | 修正後は該当なし |
| `timeout` | 0 | 修正後は該当なし |

### `redirect`

`https://ai.google.dev/gemini-api/docs/deep-research` はHTTP検査では302になったが、公式ページの本文と `curl` のHTTP 200応答を別経路で確認した。Cookieや地域パラメータによる転送挙動であり、リンク切れではない。

### `anti-bot`

次の7件は今回、公式ページまたは公式仕様を検索サービスで取得して有効性を確認した。

- W3C RDF Schema名前空間
- NIH controlled-access data notice
- NIH Genomic Data Sharing Policy
- *Introduction to Algorithms*（MIT Press）
- rsync technical report
- Collins Word of the Year
- HHS HIPAA cloud service FAQ

次の5件は、[`pending_url_review.md`](./pending_url_review.md) にある過去の手動確認記録を引き継いだ。

- DOI 3件
  - `https://doi.org/10.1093/comjnl/27.2.97`
  - `https://doi.org/10.1145/3287560.3287596`
  - `https://doi.org/10.1162/tacl_a_00638`
- `https://www.biostars.org/`
- `https://zenodo.org/`

`https://researchmap.jp/dritoshi` はHTTP検査と検索サービスの両方で403になった。著者ページのため誤リンクの可能性は低いが、このセッションでは実ブラウザ表示を確認できなかった。確認手順は[`2026-07-29_url_browser_handoff.md`](./2026-07-29_url_browser_handoff.md)へ引き継いだ。

### `connection_error`

次の4件はローカルHTTP検査でタイムアウトしたが、検索サービスではページタイトルと本文を取得できた。

- `https://www.catb.org/~esr/faqs/smart-questions.html`
- `https://www.catb.org/~esr/writings/taoup/html/`
- `https://www.gnu.org/software/bash/manual/`
- `https://www.gnu.org/software/coreutils/manual/`

したがって、原稿のリンク切れではなく、実行時のネットワーク経路または一時的応答遅延と判定した。

## 修正内容

1. 廃止されたGitHub Copilot privacyページを、個人契約と組織契約の差を明記する現行GitHub Terms of Serviceへ更新した。
2. GitHub Copilot Trust Centerを、GitHub公式ページが案内する現行の専用Trust Centerへ更新した。
3. NIH Genomic Data Sharing Policyの恒久転送先へ更新した。
4. 転送先が認証ループになるUCSC論文DOIを、同一論文のPubMedページへ更新した。
5. Catbの旧HTTP URLを、検索サービスが収録する現行HTTPS URLへ更新した。
6. Claude Opus 4.7の旧個別ページが別モデルへ転送されるため、同じ記述を裏付ける現行の公式prompting guideへ更新した。
7. 用語集の例示DOI `10.xxxx/xxxxx` をダミーURLとして機械検査対象から除外した。
8. URL検査器を修正し、HEADだけ403になるサイトではGETへフォールバックし、302転送ループをリンク切れと誤判定しないようにした。
9. TLS証明書検証を無効化していた処理を除去し、通常の証明書検証を有効にした。

本文の主張や説明は変更していない。URL、リンクラベル、参考文献メタデータ、およびレビュー用検査コードだけを更新した。

## 結論

確定した404とHTTPエラーは0件となった。HTTP検査で残る17件は、サイト側制限または実行経路固有の事象として説明できる。ブラウザでしか最終確認できない著者researchmapページ1件は任意確認として引き継ぎ、原稿修正の必須残件とはしない。
